# AFKJ 界面与动作命名规范

> 版本：v1.8.0（2026-09-03） · 适用范围：`afk_gui.py`（桌面工具）、`afk_bot/`（自动推图）、`tasks/`（任务层）（v2.0.0 更新）
> 目的：统一各界面与动作的称呼，供后续开发（ADB 版 / 新玩法任务）复用同一套术语。

---

## 0. 总则

1. **界面一律用游戏内实际名称**（挂机关卡 / 玩法目录 / 世界 / 家园…），禁止自造「主界面 / 挂机页 / 挂机推图 / 主城」等歧义称呼。
2. **用「X级菜单」描述层级**，判断标准只认 ESC 行为（见 §1）。
3. **0 层是抽象层**，含两个并列子类——**世界**（world）与**家园**（home），共用底菜单，通过右下角「世界」/「家园」按钮互切。
4. **动作用两字动词**（加 / 删 / 换 / 开 / 收 / 回 / 复 / 清…），方法名保持英文 snake_case，中文名用于注释与文档。
5. **一词一义**：同一个英文词只允许一个概念。历史教训：`formation` 曾同时指「备战界面」与「阵容」→ 现已拆分为 **备战态**（界面）与 **阵容**（队伍配置）；`town` 曾指「主城」自造词 → 现已拆分为 **`world`**（世界）与 **`home`**（家园）。

## 1. 菜单层级坐标系（识别标准）

| 层级 | 概念 | 判断标准 | 典型界面 |
|------|------|---------|---------|
| **0层** | 抽象层（世界/家园并列） | 按 ESC → 弹出「是否退出游戏」 | **世界**、**家园** |
| **1级** | 功能大厅 | 按 1 次 ESC → 退回 0层 | 玩法目录、公会、英雄厅堂 |
| **2级** | 玩法内页 | 按 1 次 ESC → 退回 1级 | 挂机关卡、活动页、异界迷宫（v1.7.2+） |
| **战斗流** | 非菜单 | 从 2级 挂机关卡触发，ESC 行为特殊 | 备战 → 战斗 → 结算 |
| **系统态** | 非菜单 | 加载/弹窗/登录等过渡 | 加载、登录、确认框、暂停、选项菜单 |

> ⚠️ 代码历史误称：「主界面」曾同时指代 0 层与 2 级挂机关卡；「主城」曾指代世界（无游戏内称谓自造词）→ **均已禁用**。
> 战斗中 / 结算中按 ESC 不等于退回上一级菜单，战斗流态不参与菜单级数。

### 0 层两个并列子类（detector 拆分）

> 切换按钮规则：右下角按钮显示**「目的地」**字样（同一位置互斥显示）。
> - 当前在世界 → 显示「**家园**」按钮（点击可切到家园）
> - 当前在家园 → 显示「**世界**」按钮（点击可切到世界）

| 标识符 | 游戏内名 | 显示的切换按钮 | OCR 识别特征 | 备注 |
|--------|---------|---------------|-------------|------|
| `world` | 世界 | 右下角「家园」 | 有「玩法目录」字样 + **识别**「家园」按钮文字 | OCR 实测「家园」按钮文字稳定 0.98 置信度（正向判断） |
| `home` | 家园 | 右下角「世界」 | 有「玩法目录」字样 + **未识别**「家园」按钮文字 | OCR 实测「世界」按钮文字完全识别不到，故 home 判定走反向推断 |

### 导航下钻链（赴战路径）

```
0层 (world | home)  ──点「玩法目录」──▶  玩法目录 (1级, playbook)
玩法目录 (1级)      ──点「挂机关卡」──▶  挂机关卡 (2级, idle_stage)
挂机关卡 (2级)      ──点「挑战」──────▶  备战 (战斗流) → 战斗 → 结算
```

> 注：世界和家园两个 0 层界面底菜单相同（都含玩法目录/英雄厅堂/公会），赴战链两个起点都成立；`esc_to_level0()` 终点统一为 0 层（世界或家园均可）。

## 6. 导航动作术语

| 中文名 | 代码方法 | 含义 |
|--------|---------|------|
| 识屏 | `detect_phase()` | 识别当前画面态（含 world/home） |
| 赴战 | `navigate_to_idle_stage()` | 下钻到挂机关卡页（0层→玩法目录→挂机关卡） |
| 待战 | `wait_for_idle_stage()` | 等待挂机关卡态 / 备战态出现 |
| 回城 | `esc_to_level0()` | ESC 连发退回 0 层（世界/家园均可，含退出弹窗处理） |
| 清障 | `_handle_common_phase()` | 消化系统态（加载/登录/弹窗/结算/暂停/选项） |
| 复位 | `_recover_to_idle_stage()`（loop） | 异常后恢复到可用状态（挂机关卡/备战优先） |
| 换阵 | `switch_formation()`（formation） | 切换阵容 |
| 开战 | `prepare_and_start_battle()` | 备战并开战 |
| 挑战 | `click_challenge_btn()` / `ocr_click_challenge()` | 点击挑战按钮（auto 点「自动挑战」/ manual 点「战斗」） |
| 收尾 | `step_close_result()`（battle） | 分步关闭结算界面 |
| 探秘 | `run()`（labyrinth） | 迷宫全流程：导航→点进入→玩法循环（选门/开战/烙印/结算） |
| 开战（F） | `press_f()` / `send_key_f()` | 发送 F 键开始战斗（迷宫备战画面，v1.7.12） |

### 状态机速记

> **赴战**（下钻：0 层 → 玩法目录 → 挂机关卡）→ **挑战** → **开战** → 战斗态 → 结算态 → **收尾** → 回挂机关卡；
> 任意时刻遇系统态一律 **清障**；异常随时 **复位**（挂机关卡/备战优先）；需要回根则 **回城**（0 层）。

## 7. 禁用语对照表

| ❌ 禁用 | 原因 | ✅ 替换 |
|---------|------|---------|
| 主界面 | 曾同时指 0层与 2级挂机关卡，歧义 | 按语境：世界/家园（0层）或 挂机关卡（2级） |
| 主城 | 非游戏内称呼（游戏内叫「世界」），自造词 | 世界 |
| 挂机界面 / 挂机页 / 挂机推图 | 非游戏内名称 | 挂机关卡 |
| 玩法书 | 翻译腔 | 玩法目录 |
| 城镇 | 非游戏内称呼 | 世界/家园 |
| 推图主界面 | 同上 | 挂机关卡 |

> ⚠️ 代码函数名 `is_on_level0()`（detector，v1.7.6 前为 `is_on_main_screen()`）检测的是 **0 层（世界/家园任一）**——注意它检测的是层级而非 2 级挂机关卡（后者 phase 为 `idle_stage`）。细分子方法 `is_on_world_screen()` / `is_on_home_screen()` 可用于需区分的场景。

## 8. 后续开发自查清单

- [ ] 新界面命名：查 §1 判断是几级菜单 → 0 层需进一步判断是世界还是家园（detector 输出 `world`/`home`）→ 用游戏内名 +「态」后缀（画面态）或「栏/抽屉」（GUI 面板）
- [ ] 新动作命名：两字动词，查 §4/§6 避免与既有动作重名（历史教训：`_toggle_drawer` 撞车）
- [ ] 注释/日志中出现「主界面」/「主城」→ 按语境改写（§7）
- [ ] 日志文案（用户可见）与注释、文档使用同一套术语
- [ ] 0 层相关导航：`phase in ('world', 'home')` 表示 0 层泛指；单独区分用 `phase == 'world'` / `phase == 'home'`
