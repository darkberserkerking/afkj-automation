## 3. 校验与兜底（新增）

| 场景 | 改造前 | 改造后 |
| --- | --- | --- |
| `navigate_to` 目标不存在 | 一条 `[警告]` 后 `return False`（易被忽略） | `[错误] 未知导航目标: 'xxx'——未登记在 NAV_TARGETS，可用目标: [...]` |
| `navigate_to` 目标精确画面未登记层 | 无校验（运行时判层 None 空转） | 提前报 `[错误] ... 未登记在 _SCREEN_LAYER，无法判层` 并返回 False |
| `step()` 目标不存在 | `NAV_TARGETS.get(target, (1,''))` **静默退化成 1 层**（导航跑偏） | `[错误] 导航步进遇到未登记目标` + 返回 False |
| 同层不同页（公会 vs 玩法目录/活动页签） | `guild` 无精确判定 → **假到达** | `_LAYER_EXACT_SCREEN['guild'] = 'nav.guild'` |
| 推图导航 | 仅老状态机 | 优先全局导航，失败自动降级 |
