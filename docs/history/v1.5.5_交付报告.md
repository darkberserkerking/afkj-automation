## 一、任务行遮挡根修（用户反馈多轮未根治的问题）

### 根因（几何测量实测，非猜测）

```
row: h=44（固定高度 + pack_propagate(False)）
  mid:      y=0  h=44  ← 白底贴满整行 → 盖住上下边框直线段
  lbl_name: y=4  h=28  ← CTkLabel 默认高 28
  lbl_sum:  y=32 h=8   ← 摘要被压缩到 8px，11px 字体溢出压底边框
```

两个根因同时作用：
1. **44px 固定行高装不下两个默认 28px 的 CTkLabel**（合计 56px），pack 算法把次要行（摘要）压缩到 8px → 文字被裁、压边框线
2. **customtkinter 的 `fg_color='transparent'` 不是真透明**，而是绘制父级底色 → mid 白底矩形（y=0..44 全高）直接盖住行 canvas 上画的边框直线段

### 修复（`_add_task_row` 内部布局重构）

- row 去掉固定 `height=44` + `pack_propagate(False)`，行高由内容自适应
- 所有子组件显式小高度：手柄/图标 20、名称 20、摘要 16
- mid 上下 `pady=5`，白底与边框之间留呼吸空间

修复后实测：row=46px / lbl_sum=16px 完整 / mid y=5..41，边框完整露出。

## 沉淀的两条 customtkinter 铁律

1. **固定高度容器内的所有子组件必须显式设 height**——CTkLabel 默认 28px，塞两行必压缩
2. **`transparent` 是画父级底色不是真透明**——贴边框的内容区必须 pady 留缝，否则盖住 canvas 边框
