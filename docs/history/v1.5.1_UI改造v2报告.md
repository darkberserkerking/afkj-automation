## 一、需求

按 MaaEnd v2.26.0 界面目标对齐（用户拍板）：
1. P0-P3 全做（行内重做 / 底部操作区 / pill 状态 / 拖拽排序 / 浅色 / 窗口加宽）
2. **切换浅色主题**
3. 不做：顶部 Tab 套件、实时截图区
4. **删除 STATS 栏**（信息由日志承载）
5. **状态栏并入 Header 同一行**
6. 左栏（任务清单）面积 ≥50% + **中间可拖分隔条**调比例
7. 注意文字/图标不溢出、不遗漏

## 二、改动清单

### `task_registry.py`（order 持久化）
- 新增 `_order` 列表：`register()` 维护、`get_all()` 按 order 返回
- 新增 `move(task_id, delta)`：拖拽交换，越界返回 False
- `save_config()` → 新格式 `{"enabled": {...}, "order": [...]}`
- `load_config()` 兼容旧格式 `{id: bool}`（自动迁移）

### `afk_gui.py`（大改，9 块）

| # | 改动 |
|---|------|
| 1 | **浅色 Token**：BG `#f5f7fa` / 卡片白 / 文字 `#0f172a` / ACCENT `#3b82f6`；`appearance_mode('light')` + `blue` 主题；日志 tag 全部适配浅色 |
| 2 | **窗口 1024×800**，minsize 800×600 |

## 三、QA 审查与修复（独立验证）

无 P0。**P1（拖拽排序）已修复**：`_render_task_rows` 销毁重建会中断手柄绑定 → 改为 motion 只改内存 order、release 统一重排，连续多格有效；motion 补 `_running` 保护。

P2 修复：勾选框选中色 `fg_color=ACCENT`（原来灰底勾不可见）；pill 对比度（完成 `#059669` / 已停止 `#d97706`）；初始化失败色 `#dc2626`；右栏最小宽 240px。
