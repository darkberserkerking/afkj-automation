## 三、实施中踩的坑（都记进项目记忆了）

1. **"与上一次比较"去重对振荡序列完全无效** —— `unknown → door → battle_prep` 每帧都"变化"，实测连续重复仅 2.2%。第一版按这个思路写完，测试立刻打脸（30 帧一条没省）。**正解是全局时间限流**。
2. **heredoc 里写含反斜杠的 f-string** → Python 3.11 语法错。项目铁律「多行补丁一律 Write 脚本文件」我又踩了一次。
3. **补丁脚本漏了 `has_self` 过滤** → 把 `self.log` 插进了 `base.py` 顶部的**模块级** import 保护。是靠"逐文件独立断言 + 全量编译 + F821 扫描"抓出来的。
4. **测试桩未对齐真实接口**：`_FakeNav` 缺 `last_screen`。真机安全（`GlobalNavigator.__init__` 就初始化），但桩会崩 → **修桩**而不是在生产代码里加 try。同时把 4 处诊断取值改成 `getattr(nav,'last_screen','')`（诊断代码绝不能自己抛异常）。
