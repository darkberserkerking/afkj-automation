# v1.5.7 交付报告：添加抽屉细胞网格 + 拖拽动画

## 功能 A：添加任务细胞网格（参考用户截图）
- 每组任务一行组标题 `组名 (n)`，下方等宽细胞网格（一行最多 4 个，grid uniform 自动等宽，细胞间留缝）
- 细胞结构：`+`（planned 任务显示 🔒）+ 图标 + 任务名称 + 已添加数量徽章（未添加完全不显示）
- 点击细胞任意位置 → 添加一个该任务实例，**成功后自动收起抽屉**
- 点击未实现（planned）任务 → 不添加，日志栏红字提示「XX 尚未实现，无法添加」

## 功能 B：拖拽动画
1. **半透明态**：按住手柄 `⠿` 时被拖任务条变浅灰底 + 文字变淡（CTk 不支持真 alpha，用配色模拟）；松开恢复
2. **实时换位**：拖动跨过阈值（半行高 26px）时，上下任务条即时让位——只重排 pack 顺序不销毁组件，手柄持续拖动不中断；展开中的行内抽屉跟随自己的行移动
