# v1.5.3 — 任务实例化架构重构报告

> 日期：2026-09-01 | 状态：源码完成（未打包） | 原则：彻底重构，不走捷径

---

## 一、需求

1. 底部「添加任务」列出**所有任务**（含已添加）
2. **同种任务可多次添加**（如多个自动推图）
3. 自动推图任务**指标**（下拉菜单/弹窗）：时间 / 轮次
   - 未设定 = 两个都无限；兜底 = 全部关卡完成自动结束
   - 有设定 = 任一满足即结束（OR 逻辑）
4. 任务条显示 **`HH:MM:SS || XX轮`**（已运行时间 + 当前轮次）

## 二、架构改动

### `task_registry.py`（全量重写）
- `TaskMeta` 扩展：`icon` / `group` / `status`（`ready` 可调度 / `planned` 占位）
- 新增 `TaskInstance`：`inst_id`（class#N 自动编号）/ `class_id` / `enabled` / `options` / `max_time` / `max_turns`
- `TaskRegistry` 实例管理：`add_instance` / `remove_instance` / `set_instance_enabled` / `set_instance_metrics` / `move_instance`
- 持久化：`tasks_enabled.json` 新 schema `{"instances": [...], "order": [...]}`；旧格式 `{id: bool}` / `{enabled, order}` **自动迁移**
- 踩坑修复：`_CONFIG` 统一用类属性（模块级/类级混淆导致测试覆写失效）

### `tasks/catalog.py`（新增）
`TASK_CLASSES` 统一映射（scheduler 与 GUI 共用，避免循环 import）：
`auto_farm`(ready) / `daily_quest`(planned) / `goddess_challenge`(planned) / `tower`(planned)

### `tasks/tower.py`（新增，planned 占位）
`preflight()` 返回 "任务未实现（planned）" → 调度时 skipped

### `tasks/base.py`
- ctx 新增 `max_time` / `max_turns` / `start_turns` / `inst_id`
- `turns` 属性（相对实例启动的轮次增量）
- `check_completion()`：时间/轮次 **OR 逻辑**，任一满足返回 True

### `afk_bot/core.py`
- `run_auto_farm(max_time, max_turns, start_turns)` 注入指标
- 主循环顶部 `_task_completion_reached()` 检查，达标 break 返回 done
- `all_completed` 置 `_task_completed` → 全通关返回 **done**（非 stopped）

### `tasks/scheduler.py`（全量重写）
- `add(inst: TaskInstance)`；按实例调度，ctx 注入全部实例参数
- `_notify` 带 `inst_id`（GUI 按实例更新状态）

### `afk_gui.py`
- 清单渲染**实例**：44px 行 = 手柄 + 勾选 + 图标 + 名称[×N 徽章] + 摘要[含指标] + pill + ⚙ + `+` + ›
- 「+ 添加任务」弹窗：按组分列全部任务类（含 status 徽章：可运行/开发中）
- ⚙ 指标弹窗：时间/轮次（留空 = 无限）
- 运行时 `_refresh_timer` 刷新行内 `HH:MM:SS || XX轮`
- `_on_start` / `_bot_thread_wrapper` / 批量勾选 / 拖拽排序 / 六态 全改实例维度
