# v1.5.4 抽屉化改造报告

## 需求回顾

1. 删除任务行的 [⚙][+] 两个按钮
2. 任务名称固定为「自动推图」（不需要重命名、不需要 ×N 徽章）
3. 行最右侧添加 `›` 和 `X`（X 在最右）
4. `›` 打开**行内下拉抽屉**（非弹窗），X 删除当前任务
5. 底部「+ 添加任务」改为**抽屉**（非弹窗）
6. **所有功能整合在一个窗口内，通过菜单或抽屉形式，禁止弹窗**

## 核心修复：抽屉静默崩溃

**现象**：点击 `›` 无反应，冒烟测试在抽屉展开步骤静默中断。

**根因**：`afk_gui.py` 存在**方法重名覆盖**——v1.5.2 的设置抽屉（右上角齿轮 ⚙）与新任务行抽屉都定义了 `_toggle_drawer`，Python 后定义覆盖前定义（1137 行覆盖 781 行），调用 `self._toggle_drawer(inst.inst_id)` 报 `TypeError: takes 1 positional argument but 2 were given`。py_compile 查不出（纯运行时错误），异常被测试脚本吞掉。

**修复**：设置抽屉整套重命名：
- 方法：`_toggle_settings` / `_open_settings` / `_close_settings` / `_settings_anim_step`
- 属性：`_settings_drawer` / `_settings_open` / `_settings_inner` / `_btn_settings_close`

## 附带修复

| 问题 | 级别 | 修复 |
|---|---|---|
| 抽屉 `pack_forget()` 后重新 `pack()` 排到列表末尾，不紧跟自己的行 | P1 | `drawer.pack(..., after=row_frame)` 定位 |
| `winfo_ismapped()` 对刚 pack 的 widget 返回 False，展开态误判 | P1 | 统一改用 `winfo_manager() == 'pack'` 判定 |
| 抽屉互斥不对称：设置抽屉 ↔ 任务/添加抽屉可同时展开，遮罩重叠 | P1 | 统一互斥 `_close_task_drawers(except_id)` / `_close_add_drawer` / `_close_settings_drawer` |
| Esc 只能关设置抽屉，其它抽屉没退路 | P1 | Esc 绑定 `_close_all_drawers()` 全关 |
| 展开态按钮文本 `^` 字形不统一 | P2 | 改为 `▾` |
