### 2. 连败不切模式 bug 修复（本次核心）

**症状**：同模式连败 >10 次仍不切换（v1.5.0 日志：失败 10/11 次仍幻灵挑战）。

**根因链**（现场截图 + OCR/模板实测坐实）：
1. `>` 是纯图标按钮 → OCR 永远找不到，模板匹配是唯一手段（设计正确）
2. 原模板（48×50）**全屏模板匹配**在第 10 套（`>` 消失）时**误命中底部"一键采用"按钮**（conf=0.708 ≥ 0.6）→ `still_match=True` → `_switch_exhausted` 永不置位 → 切模式永不触发
3. 失败分支 `formation_idx>=10` 只重置 0 不切模式（死循环兜底是坏的）
4. 附证：AFKJ_Android 紫圆模板（115×115，PNG 透明背景 cv2 不处理 alpha → 模板不纯）在 PC 上 conf=0.494 找不到按钮，反命中其他紫色装饰 —— 不可用

**修复**（备份 `backup/formation_v1.5.1_pre_arrowfix.py` / `core_v1.5.1_pre_arrowfix.py`）：
| 文件 | 改动 |
|------|------|
| `formation.py` | 新增 `_switch_btn_region()`（面板右侧竖条 x=0.60~0.88, y=0.25~0.75）；`switch_formation` 找按钮+验证模板匹配加 region；`has_switch_button(region=None)` OCR 位置过滤 |
| `templates/btn_arrow_right.png` | 替换为从用户截图精确裁剪的 **56×56 新模板**（原 48×50 备份 `backup/btn_arrow_right_v1_48x50.png`） |
| `core.py` | 两处失败分支（战斗失败 + `_pending_defeat`）`formation_idx>=10` 兜底改**强制切换挑战类型** |

**验证**：
| 项 | 结果 |
|----|------|
| py_compile | ✅ |
| 任务层冒烟 17/17 | ✅ |
| 模板区分度（region 内） | ✅ 有 `>` 图 conf=**1.000** / 第10套 conf=**0.538**（<0.6 不误命中） |

**修复后的判定链**：第 10 套 `>` 消失 → region 内 conf=0.538 → `still_match=False` + OCR 无 `>` → `_switch_exhausted=True` → 切模式 ✓；极端情况 region 误命中 → `formation_idx>=10` 兜底再保一道 ✓
