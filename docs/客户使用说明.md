# AFKJ 自动化助手 · 使用说明

帮你自动完成 AFK Journey（剑与远征：启程）的日常玩法：**勾选要跑的内容 → 点运行，其余全自动。**

---

## 一、使用前准备

1. **以管理员身份运行游戏**（否则按键/点击可能无效）
2. 打开游戏，停在**任意界面**都可以 —— 工具会自己导航过去
3. 双击 `AFKJ自动化工具.exe` 启动工具

---

## 二、四步上手

| 步骤 | 操作 |
|---|---|
| 1 | 双击 EXE 启动 |
| 2 | 勾选要跑的玩法（列表为空就点 **`+ 加任务`**） |
| 3 | 要改参数就**点任务行**，改好点「确定」 |
| 4 | 点 **`▶ 运行`**（快捷键 **F11**） |

**停止**：点 **`■ 停止`** 或按 **`F12`**（全局生效，随时可按，立即停止）。

---

## 三、支持的玩法

| 玩法 | 作用 |
|---|---|
| 🤖 自动推图 | 幻灵 / 普通挑战交替推进，连败自动换阵容，通关后结束 |
| 🌀 异界迷宫 | 逐层选门、战斗、领奖励 |
| 🌟 女神试炼 | 挑战到当前上限层，再扫荡拉满奖励 |
| 🏠 一键家园 | 愿望单自动刷单（可选是否消耗体力） |
| ⚔ 竞技场 | 自动挑战至票数用尽（可设黑 / 白名单） |
| 📋 每日任务 | 一键领取每日任务 + 活跃度奖励 |
| 🎁 收赠友情点 | 一键赠礼并收礼，收满即完成 |
| 💠 迷梦之域 | 进入迷梦之域挑战 |
| 🚀 启动游戏 | 游戏没开就自动拉起 |
| 🛑 关闭游戏 | 运行中则优雅关闭 |

> 玩法可**任意组合、按顺序执行**，同一种也能加多次。推荐日常组合：
> `启动游戏 → 自动推图 → 每日任务 → 收赠友情点 → 关闭游戏`

---

## 四、要设置的参数

只有下面几项有参数，其余点开显示「无参数」。

| 玩法 | 参数 | 说明 |
|---|---|---|
| 异界迷宫 | 运行模式 | **模式1：通关 15 结束**（默认）· **模式2：20 关前停止（单核）** · **模式3：20 关前停止（双核）**；模式 2/3 打完 19 关后停在首领门前，烙印库存达标即结束，不达标则打掉首领重来 |
| 一键家园 | 消耗体力 | 刷完愿望单后自动消耗体力 |
| 一键家园 | 保留体力 | 0~5000，**需先勾选「消耗体力」**才生效 |
| 竞技场 | 挑战黑名单 | 角色名用 **`;` 或 `；`** 分隔（**不是逗号**），永不挑战 |
| 竞技场 | 挑战白名单 | 角色名用 **`;` 或 `；`** 分隔（**不是逗号**），优先挑战 |
| 迷梦之域 | 重复挑战至次数耗尽 | 不勾选则只打一次 |
| 自动推图 | 时间上限 / 轮次上限 | 填「无限」表示不限 |

## 五、界面说明

**顶部按钮**

| 按钮 | 作用 |
|---|---|
| `▶ 运行` / `■ 停止` | 同一个按钮，运行中变红为「停止」 |
| `+ 加任务` | 打开面板添加玩法 |
| `⇅ 全部展开` | 展开 / 收起任务详情 |
| `☐ 全选` | 一键勾选 / 取消全部任务 |
| `⏱ 定时` | 设定时间，到点自动开始 |
| `⚙ 设置` | 工具设置（含窗口置顶） |

**任务行**：点勾选框启用 / 停用 · 按住拖动调整顺序（**从上到下依次执行**）· 点一下改参数 · 右侧按钮删除。

**日志区**：实时显示工具在做什么。`[信息]` 进展 · `[成功]` 完成 · `[警告]` 异常但会自动重试 · `[错误]` 失败 · `[点击]` 正在操作。任务行右侧显示 **完成 / 失败 / 未勾选 / 跳过**。

---

## 六、注意事项

1. **运行期间不要操作鼠标键盘** —— 工具会真实移动鼠标点击游戏；也不要点 F11。
2. **不要遮挡或最小化游戏窗口** —— 工具需要看得见画面。
3. **任务按顺序执行**；某个任务失败会**停止后续任务**（避免在异常状态下继续操作）。
4. 想手动接管游戏，先按 **F12** 或点「■ 停止」。

---

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 点运行但游戏没反应 | 游戏要用**管理员身份**运行 |
| 找不到游戏窗口 | 确认游戏已启动、窗口未被完全遮挡 |
| 某个玩法卡着不动 | 停止后重跑；反复出现就把日志发给技术支持 |
| 竞技场打到了不想打的人 | 把他名字填进「黑名单」 |
| 家园把体力用光了 | 关掉「消耗体力」，或填「保留体力」 |

> 运行期间**先点「停止」再改任务**（运行中不能加 / 删 / 改任务）。
