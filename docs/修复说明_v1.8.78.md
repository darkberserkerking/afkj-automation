# v1.8.78 修复说明：跳过按钮模板 FileNotFoundError

## 问题
真机日志（14:04 / 14:14 两次）：

```
[警告] ⚠️ 多尺度模板匹配异常: [Errno 2] No such file or directory: 'btn_skip_battle.png'
```

v1.8.77 已把裸名 `btn_skip_battle` 补成 `btn_skip_battle.png`，仍然报错 → 根因不在后缀。

## 根因
1. exe 二进制内**确有**该模板（二进制 grep 命中 `btn_skip_battle.png`），spec `datas` 含 `('templates','templates')` → 打包没漏。
2. `InputController.template_match()` 直接用入参读盘（`np.fromfile(tpl_path)`）。
3. 调用方传的是**裸文件名** → 按**进程当前工作目录**解析；exe 放在 `D:\桌面` 时 CWD 就是桌面，而模板实际在 `sys._MEIPASS\templates\` → 必然找不到。

对比：`btn_back_*` / `btn_door_*` 全部走 `_TEMPLATE_DIR` 绝对路径，所以一直正常。
