## 五、遗留假设（需你确认）

1. **P0-1 反向依赖未改**——假设：当前"任务注册发生在 `afk_bot` 包导入时"是 GUI 依赖的行为，删除会破坏启动。若你确认可以改注册时机（如改为 GUI 显式调用），我可以根治并附完整启动验证。
2. **P0-3/4/5 静默异常与失败语义未改**——假设：这些路径改动会影响推图判定与高频日志量，需真机连跑验证；本轮优先保证稳定。
3. **P1-10/11 GUI 重构未做**——假设：你更看重功能稳定而非视觉重构；若需要，建议单独开一轮（组件抽取 + 配色/字体常量收敛 + 逐屏截图比对）。
4. **`nul` 文件**——安全删除机制拒绝删除 Windows 保留名，假设可保留或由你手动处理。
5. **11 处"从 afk_bot.py 提取"的历史 docstring**——判定为低收益，假设保留可接受。
6. **P2-4 日志英文残留（`hwnd=` 等）**——假设优先度低于功能修复，随后续界面登记一并收敛。
