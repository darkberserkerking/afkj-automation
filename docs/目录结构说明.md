## 三、命名规范

| 类型 | 规范 | 示例 |
|---|---|---|
| 玩法任务 | `tasks/<玩法英文名>.py`，类名 `<Xxx>Task`，类属性 `task_id = '<英文名>'` | `tasks/daily_quest.py` → `DailyQuestTask` |
| 测试用例 | `tests/test_<被测对象>.py`；独立验证另起 `test_<对象>_verify.py` | `test_daily_quest_dryrun.py` |
| 图像模板 | `templates/btn_<用途>.png`（按钮）/ `<对象>_<用途>.png` | `btn_confirm_cancel.png` |
| 源码备份 | `backup/<模块>_v<YYYYMMDD>_<HHMM>.py` | `labyrinth_v20260911_1728.py` |
| 打包产物 | `AFKJ自动化工具v<主>.<次>.<补丁>.exe`，版本号唯一真相源 = `afk_bot/config.py` | `AFKJ自动化工具v2.2.0.exe` |
| 交付说明 | `docs/history/overview_v<版本>.md`；当前版 = 根目录 `overview.md` | `overview_v1.6.3.md` |

**新增文件该放哪**：源码 → 对应包目录；文档 → `docs/`；临时验证脚本 → `tests/tools/`；备份 → `backup/`；**不要往根目录丢文件**。
