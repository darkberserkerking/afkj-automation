# 坐标规范（v1.8.56 定稿）

> 依据 2026-09-07 全库坐标排查（afk_bot/ + tasks/ 逐 file:line 审查）与
> v1.8.53/v1.8.55/v1.8.56 三次坐标事故沉淀。**新代码必须遵守，改动涉及
> 坐标时先读本文。**

## 一、两套坐标系

| 坐标系 | 原点 | 单位 | 产出处 |
|---|---|---|---|
| **图像坐标系** | 截图/客户区左上角 | 像素（真机约 1280×1024） | OCR、`ratio_to_image` |
| **屏幕坐标系** | 主屏 (0,0) | 像素 | `template_match`、pyautogui 直点 |

## 二、数据结构约定（单一真相源）

| 结构 | 约定 | 真相源 |
|---|---|---|
| OCR 条目 items | `(cy, cx, text, conf, x_min, x_max)` —— **it[0]=y, it[1]=x** | `infra/screen.py::ocr_screen` |
| find 系返回值 | `(cx, cy)` —— **x 在前** | `infra/ocr_engine.py::_find_text_impl` |
| 点击入参 | `click_at(cx, cy)` / `click_abs(cx, cy)` / `click_ratio(rx, ry)` —— 先 x 后 y | `infra/input.py` |
| 矩形区域 region | `(x, y, w, h)`，屏幕坐标，numpy 切片按 `[y:y+h, x:x+w]` | `infra/input.py::template_match` |
| OCR roi | `(rx, ry, rw, rh)` **比例** | `infra/ocr_memory.py` |
| 滚动区域 | `(x0, y0, x1, y1)` **比例点对** | `tasks/goddess_trial.py::_SCROLL_REGION` |

⚠️ region 有三种形态并存（像素 wh / 比例 wh / 比例点对），写代码时先确认
调用方预期，勿凭直觉。

## 三、转换规则

- `image_to_screen(x, y)` ↔ `screen_to_image(x, y)`：互逆，位于
  `infra/coordinate.py::CoordSystem`；facade 已透传 `screen_to_image`。
- 图像→屏幕的平移量 = `CoordSystem.client_offset`（客户区左上角屏幕坐标），
  **不是** `win_dims()` 左上角（窗口矩形含边框装饰）。v1.8.56 起
  `loop._screen_offset()` 优先取 client_offset（Unity 无边框窗口两者等价）。
- 同一元组只能有一种轴序语义：**传给别人的位置元组一律 `(cx, cy)`**；
  拆 OCR 条目时立即显式具名 `cy, cx = it[0], it[1]`。

## 四、分工铁律（隐式约定成文，违例=bug）

1. **OCR 命中 → `click_at`**（图像坐标，内部自转屏幕）。
   唯一例外链：无（v1.8.56 已修 formation.py OCR 分支直点 `click_abs` 的混流）。
2. **模板命中 → `click_abs`**（屏幕坐标），或 `screen_to_image` 转回图像后
   `click_at`。
3. **组合点击**（OCR 定位一轴 + 模板定位另一轴，如迷宫选门"标题 x + 按钮 y"）：
   必须先 `screen_to_image` 统一回图像系再 `click_at`（参照 `tasks/labyrinth.py::_pick_door`）。
4. 硬编码中心点（如 `click_at(640, 512)`）按**图像系 1280×1024** 假设；
   比例点按 `(rx, ry)`。新增此类点优先用比例坐标。

## 五、解包与命名规范（防 v1.8.55/56 类事故）

1. 拆 OCR 条目**禁止反置命名**：`for cx, cy, ... in items` 是错的（items
   首元是 cy）。安全写法二选一：
   - 具名且顺序正确：`for cy, cx, text, conf, *_ in items:`
   - 显式索引：`x = it[1]; y = it[0]`（含注释时优先）
2. 判定"坐标轴用没用反"的快速自检：
   - 与 `x_min/x_max`（it[4]/it[5]）比较的变量必须是 x；
   - 与 `h/高度比例`（如 `0.55*h`）比较的变量必须是 y；
   - `/1280` 的是 x，`/1024` 的是 y。
3. 多个同名词文本（双门/多卡）场景：新写枚举函数返回值轴序必须与本表
   "find 系返回值"一致，并在 docstring 写明 `(cx, cy)`。
4. **测试数据必须用真实界面实测坐标**（MaaOCR 打中心点），禁止随手
   `float` 凑数——v1.8.52 的 I2 用例因数据不敏感放过轴反（"碰巧通过"）。
   测试要能区分"功能生效路径"与"降级路径殊途同归"。

## 七、遗留假设（需真机观察，暂不改）

- `formation.py::has_switch_button` region 只限 x 不限 y（轻微，误判风险低）。
- 硬编码 1280×1024 假设分散在 tasks 层；若将来支持其他分辨率，需集中到
  CoordSystem 统一换算。
